长期优质资产

NASDAQ：AMZN ｜ 分析日期：2026年11月13日 ｜ 投资周期：3–5年

我的初步判断：

亚马逊是一家非常优秀的公司，但优秀的公司不一定是任何价格都值得买入的股票。

如果从巴菲特、段永平和李录的价值投资思路来看，亚马逊最值得研究的不是网上卖商品，而是它背后的三大赚钱引擎：

  • AWS：全球云计算基础设施。
  • 电商平台：规模、物流网络和消费者生态。
  • 广告业务：利用电商流量创造高利润广告收入。

我认为，亚马逊真正的长期价值在于：它同时拥有消费入口、云计算基础设施和广告变现能力。

但现在有一个特别值得警惕的问题：AI投资正在大幅吞噬自由现金流。

参考价$266.17沿用原文2026年11月11日收盘快照，非实时行情。正常化股东收益、估值与观察区间均为研究假设。

1. AWS：亚马逊最重要的护城河

AWS面对的主要竞争对手：

  • Microsoft Azure
  • Google Cloud
  • Oracle Cloud
  • Alibaba Cloud

AWS的优势在于：

  • 企业客户迁移成本高。
  • 产品和服务种类丰富。
  • 全球数据中心网络成熟。
  • 企业开发者生态强大。
  • AI时代需要大量算力。

但我特别提醒一点：

AWS的增长不等于亚马逊一定能获得同等比例的利润增长。

AI基础设施需要巨额投入，未来需要观察投入资本回报率（ROIC）。

AMZN / VALUE RESEARCH06 / 20

2. 电商：真正难以复制的是物流网络

亚马逊的优势不是简单地比竞争对手卖得便宜，而是：

  • 商品选择丰富。
  • 配送速度快。
  • 仓储网络密集。
  • Prime会员形成消费习惯。
  • 第三方卖家增加平台商品丰富度。

它的竞争对手包括沃尔玛、Shopify、Temu以及其他本地电商平台。

这里我更看重规模经济，而不是单纯的市场份额。

AMZN / VALUE RESEARCH07 / 20

3. 广告：容易被低估的利润来源

亚马逊广告有一个很大的优势：

消费者本身就带着购买意图进入平台。

这与一般社交媒体广告不同。

例如，用户搜索某种商品时，广告可以直接出现在购物决策环节。

这使广告业务具有很强的商业价值。

我认为未来亚马逊广告业务值得单独估值，而不应该简单并入电商业务。
